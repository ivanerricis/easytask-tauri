# Security Policy

## Supported versions

Only the latest released version of EasyTask receives security fixes. Please update (Settings > About > Check for updates) before reporting.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Report it privately through GitHub security advisories: open the [Security tab](https://github.com/ivanerricis/easytask-tauri/security/advisories/new) of the repository and choose "Report a vulnerability".

Include what you can: the affected version, the steps to reproduce, the impact and, if you have one, a proposed fix. You will get an answer as soon as possible; once the issue is confirmed a fix is prepared in private and released together with a public advisory.
